# Versioni precedenti

Le versioni precedenti sono applicazioni Substance 3D compatibili con il precedente sistema di attivazione dei file delle chiavi di licenza in vigore prima della transizione all’attivazione dell’account Adobe. Queste versioni non sono compatibili con le licenze acquistate tramite il tuo account Adobe o account Steam.

Per scaricare le versioni precedenti di Substance 3D Painter e Designer, visita il seguente indirizzo:\
<https://www.substance3d.com/legacy-builds/>
