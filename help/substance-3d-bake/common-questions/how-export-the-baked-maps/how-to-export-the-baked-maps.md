# Come si esportano le mappe con baking?

>[!WARNING]
>
> **Domanda**
> 
> Come posso esportare le texture eseguite i baking dalla mesh per utilizzarle in un&#39;altra applicazione?

>[!NOTE]
>
> **Soluzione: Substance Designer**
> 
> I file di output dei Baker devono trovarsi accanto al grafico delle Substance a cui è collegata la trama. Fare clic con il pulsante destro del mouse e scegliere &quot;Esplora&quot; per visualizzare i file nella finestra Esplora risorse dell&#39;applicazione.

>[!NOTE]
>
> **Soluzione: Substance Painter**
> 
> I file di output dei Baker vengono salvati all&#39;interno del file di progetto (\*.spp). Per esportarle è possibile:
> 
> * Utilizza la finestra di dialogo **File > Esporta Texture** e scegli il predefinito di esportazione &quot;Mesh maps&quot;
> * Fate clic con il pulsante destro del mouse sulla texture di un forno nello scaffale e scegliete &quot;Esporta&quot;.

>[!NOTE]
>
> **Soluzione: Substance Automation Toolkit**
> 
> Per impostazione predefinita, i file di output dei Baker vengono salvati accanto alla trama. La cartella di output può essere modificata tramite un argomento specifico nella riga di comando.
