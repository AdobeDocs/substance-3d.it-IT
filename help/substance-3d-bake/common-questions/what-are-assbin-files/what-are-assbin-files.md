# Che cosa sono i file Assbin?

>[!WARNING]
>
> **Domanda**
> 
> Dopo la cottura in Substance Painter ho trovato uno o più file accanto alle mie trame di poly alto con l&#39;estensione di file &quot;assbin&quot;, che cosa sono? Posso rimuoverli in sicurezza?

>[!NOTE]
>
> **Soluzione**
> 
> Assbin file versioni pre-elaborate delle trame high-poly utilizzate durante il processo di cottura. Sono più veloci da leggere rispetto ai file con trama originali, il che consente di eseguire nuovamente il baking più rapidamente quando si esegue un&#39;iterazione sulle impostazioni dei panettieri. Possono essere rimossi in modo sicuro. Se necessario, Substance Painter li rigenererà. Tuttavia, questo può influire sulle prestazioni di cottura al forno.
> 
> È possibile non generare mai questi file accedendo alle [preferenze principali](https://helpx.adobe.com/substance-3d/unlisted/documentation/spdoc/general-71008262.html) della Substance Painter e disabilitando l&#39;opzione &quot;Salva file di scena preelaborati&quot;.
