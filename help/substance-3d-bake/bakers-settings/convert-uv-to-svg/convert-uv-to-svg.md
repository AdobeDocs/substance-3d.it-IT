# Converti UV in SVG

Il baker Converti UV in SVG Trasforma gli UV con trama a basso poli in un file di grafica vettoriale. Questo file di grafica vettoriale può essere utilizzato per creare maschere.

**Disponibile in:**

* Substance Designer
* Substance Automation Toolkit

## Parametri

| *Parametro* | *Descrizione* |
| --- | --- |
| **Spaziatura interna** | Controlla la spaziatura geometrica da aggiungere alle forme SVG. |
| **Modalità colore** | Definisce la modalità di colorazione delle forme SVG.Valori possibili:<ul data-preserve-html="true"><li data-preserve-html="true"><strong>Casuale:</strong> ogni shell UV è colorata con un colore casuale.</li><li data-preserve-html="true"><strong>Scostamento tonalità:</strong> ogni shell UV è colorata con un valore di tonalità univoco.</li><li data-preserve-html="true"><strong>Scala di grigi:</strong> ogni shell UV è colorata con un valore di scala di grigi univoco.</li><li data-preserve-html="true"><strong>Colore uniforme:</strong> tutte le conchiglie UV sono colorate in grigio al 50%.</li><li data-preserve-html="true"><strong>Colore ID materiale</strong>: i gusci UV sono colorati dal colore del materiale definito nella Vista scena.</li></ul> |
