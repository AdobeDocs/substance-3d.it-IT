# Applicazioni 3D

Potete importare un file di Substance (.sbsar) nella maggior parte delle principali applicazioni DCC tramite il plug-in Substance. I plug-in sono gratuiti e disponibili nel [nostro sito](https://www.substance3d.com/ecosystem-plug-ins/) o tramite un programma di installazione nativo.
