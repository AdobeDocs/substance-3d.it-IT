# Utilizzo degli output

È possibile attivare/disattivare manualmente gli output nella sezione Output.

![](../../../assets/outputs-1.png){width="800px"}

Un cerchio chiuso indica che l’output è stato creato. Nell’immagine qui sopra, potete vedere che il Colore di base è stato creato. Poiché l&#39;opzione Output cache su disco è stata abilitata, è stato creato un output Substance e un nodo di file Maya. Il nodo del file legge la texture memorizzata nella cache del disco e viene aggiornato automaticamente ogni volta che la Substance Engine elabora le texture. Fare di nuovo clic sul cerchio chiuso per disattivare l&#39;output e rimuovere i nodi.

![](../../../assets/enabled-3.png)

Fare clic sull&#39;icona dell&#39;occhiale per selezionare l&#39;output della Substance o il nodo del file. Se il nodo del file è stato creato, verrà selezionato quando si fa clic sull&#39;icona dell&#39;occhiale. Se non è presente un nodo di file, verrà selezionato l&#39;output della Substance. Ciò consente di passare rapidamente a un nodo di output o di file. *\*Suggerimento: premere il tasto F per eseguire il fotogramma del nodo selezionato nell&#39;editor dei nodi. Questo è utile quando si dispone di molti output e si deve trovare un nodo di file specifico.*
