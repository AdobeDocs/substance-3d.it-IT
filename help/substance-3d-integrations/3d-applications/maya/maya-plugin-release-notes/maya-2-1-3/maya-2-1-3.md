# Maya 2.1.3

Rilasciato il 17 giugno 2020

Oggi è stata rilasciata la versione 2.1.3 del plug-in.

2.1.3 Versione:

* Il programma di installazione è ora firmato con SHA-256 su Windows
* Tutti i file binari all&#39;interno del programma di installazione sono ora firmati su Windows
* substance\_link.dll e substance\_portal\_cli.dll ora hanno informazioni sulla versione/descrizione in Windows
* È stata aggiunta un’opzione di flusso di lavoro per la superficie standard in Maya 2020

Questa versione è stata rilasciata per Maya 2017, 2018, 2019 e 2020 su Windows, Linux e Macos. È stato pubblicato anche per Maya LT 2018, 2019 e 2020 su Windows e MacOS.
