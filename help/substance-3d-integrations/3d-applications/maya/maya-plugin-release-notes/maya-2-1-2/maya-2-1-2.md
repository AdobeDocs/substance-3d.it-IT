# Maya 2.1.2

Rilasciato il 2 giugno 2020

Oggi abbiamo rilasciato la versione 2.1.2 del plug-in.

L&#39;unica modifica che contiene è:

* È stato corretto un errore in Maya LT durante la creazione di una rete a shader stingray.

Questo è stato pubblicato anche con Maya 2020.2 ed è contenuto nel programma di installazione di Maya per quello.

È pubblicato per le stesse piattaforme, Maya 2017 - 2020 e Maya LT 2018 - 2020
