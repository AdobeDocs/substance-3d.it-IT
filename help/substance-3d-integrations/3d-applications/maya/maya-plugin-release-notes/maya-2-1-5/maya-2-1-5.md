# Maya 2.1.5

Rilasciato il 5 agosto 2020

Elenco modifiche:

* I file sbsar ora dovrebbero essere visualizzati e possono essere impostati nell&#39;editor dei percorsi dei file
* I percorsi dei file devono essere impostati dai relativi Maya durante la condivisione di un progetto
* Invia a da Avvio Substance copierà ora il file sbsar nella directory del progetto

Questa versione è rilasciata per Maya 2017, 2018, 2019 e 2020 su Linux, MacOS e Windows e per Maya LT 2018, 2019 e 2020 su MacOS e Windows
