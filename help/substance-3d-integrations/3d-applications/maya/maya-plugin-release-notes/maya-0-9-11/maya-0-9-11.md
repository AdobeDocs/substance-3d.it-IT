# Maya 0.9.11

**Modifiche a Maya 2.0:**\
**Stabilità**:

* Attributi dinamici dal grafico ora creati in modo nativo, non tramite il codice dell&#39;editor di attributi
* I nodi Substance possono essere creati in batch poiché sono inizializzati senza l&#39;input dell&#39;interfaccia utente
* Editor di attributi e editor di proprietà notevolmente più stabile
* Le prestazioni della memoria sono migliorate in modo significativo, abbastanza da consentire output 8k sul motore GPU
* Le impostazioni/preferenze ora vengono salvate come un file di configurazione separato che può essere facilmente modificato all’esterno di Maya

**Script**:

* API di scripting avanzata, con qualsiasi operazione dall’acquisizione di informazioni di input, grafico e output, al caricamento di pacchetti sbsar, alla modifica del grafico e all’esecuzione di qualsiasi operazione predefinita in Gestione predefiniti
* Codice dell’interfaccia utente progettato per utilizzare le stesse funzioni dell’API di scripting pubblica

**Substance funzionalità**:\
**Supporto predefiniti:**

* I predefiniti incorporati impostati nella finestra di progettazione vengono caricati in Gestione predefiniti
* Importare ed esportare file sbspr, inclusi più predefiniti
* Gestione predefiniti
* Supporto del motore V7
* Funziona già con il nuovo motore di Substance disponibile con Designer 2019.1
* Il rendering degli output numerici viene eseguito su un attributo di output maya sul
* Nodo grafico/substance, che può essere collegato ad altri nodi nell&#39;iperombra

**Sistema del flusso di lavoro:**

* Nuovi flussi di lavoro per Arnold, Renderman, VRay, Corona e altri ancora
* Estensioni del flusso di lavoro personalizzate in Python
* Inverti gli script del flusso di lavoro dall’area di lavoro all’ombra, configura un flusso di lavoro personalizzato una volta e salvalo
* Utilizzare un flusso di lavoro con le mappe immagine da Substance Painter

**Miglioramenti dell&#39;interfaccia utente e dell&#39;interfaccia utente:**

* File -> import .sbsar crea un nodo substance
* Trascina i file sbsar dal browser di file a hypershade per creare nodi substance 2
* Gli attributi vengono ora disposti in base alle categorie impostate in Designer

**Altri miglioramenti:**

* Gli input immagine ora funzionano con i nodi procedurali
* È ora possibile impostare la frequenza di campionamento per i nodi procedurali in modo da poter eseguire il downsampling o l&#39;upsampling delle immagini procedurali
* I nodi di output ora visualizzano le informazioni di output codificate nel Substance Designer
* I nodi Substance/grafico ora possono visualizzare le informazioni del grafico (autore, ecc.)
* Supporto per la sostituzione dei livelli, ad esempio sostituzioni di connessione e di attributi
* La cache su disco sceglie il tipo di file exr per qualsiasi output HDR, che sono output con output a 16 bit, 16 float o 32 bit float
* Riflessione dal vecchio plug-in
* Il caricamento di una scena con il nuovo plug-in convertirà i vecchi nodi del grafico e dell&#39;output in nodi substance 2
