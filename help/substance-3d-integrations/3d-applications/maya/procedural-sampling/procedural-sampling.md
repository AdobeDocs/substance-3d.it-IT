# Campionamento procedurale

Le impostazioni di campionamento procedurale consentono di controllare a quali dimensioni il plug-in campiona le texture procedurali come Browninan, Disturbo, Frattale, Mandelbrot, ecc. Queste impostazioni sono specifiche per Materiale Substance con input immagine che utilizza una texture procedurale.
