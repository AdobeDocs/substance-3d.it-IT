# Installazione

La Substance nel plug-in Maya è anche installata ufficialmente nel programma di installazione Maya 2022/2020. È abilitato all&#39;installazione per impostazione predefinita.

>[!NOTE]
>
> **Maya 2022**
> 
> **Windows**: C:\Program Files\Allegorithmic\Adobe Substance 3D for Maya\2022\
> **MacOS**: /Applications/Allegorithmic/Substance 3D per Maya/2022\
> **Linux**: /opt/Allegorithmic/Adobe Substance 3D per Maya/2022

>[!NOTE]
>
> **Maya 2020**
> 
> **Windows**: C:\Program Files\Allegorithmic\Adobe Substance 3D for Maya\2020\
> **MacOS**: /Applications/Allegorithmic/Substance 3D per Maya/2020\
> **Linux**: /opt/Allegorithmic/Adobe Substance 3D per Maya/2020

Inoltre, il programma di installazione per le versioni più recenti del plug-in può essere scaricato dalla pagina [Adobe Substance 3D per Maya](https://substance3d.adobe.com/plugins/substance-in-maya/).
