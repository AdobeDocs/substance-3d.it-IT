# Predefiniti

Nella sezione Predefiniti, potete gestire completamente i predefiniti incorporati presenti nel file Substance sbsar o crearne di nuovi.

![](../../../assets/presets-15.png)

Per creare un predefinito, apportate le modifiche desiderate al pulsante Substance parametri, quindi fate clic sul pulsante Crea.

![](../../../assets/preset-save.gif)

Per applicare un predefinito, selezionatelo dal menu e fate clic su Applica. Se devi sovrascrivere un predefinito, selezionalo dal menu e fai clic sul pulsante Sovrascrivi. Il predefinito verrà aggiornato con le nuove impostazioni. Potete anche importare ed esportare file di predefiniti di Substance (.sbsprs).
