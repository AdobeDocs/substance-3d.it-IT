# Installazione Modo

Per installare il plug-in, trascina semplicemente il file LPK in MODO. Se non avete installato un kit o il pacchetto di contenuti MODO, potrebbe essere visualizzata una finestra di dialogo che richiede di creare le cartelle appropriate. Una volta installato il kit, vedrai un pulsante Substance in alto a destra dell’interfaccia utente MODO.
