# Componente aggiuntivo 0.9.3

**Note sulla versione per il componente aggiuntivo 0.9.3+**

* Aggiungete le etichette degli spazi colore OCIO 2.0 nelle preferenze del componente aggiuntivo.
* Aggiungere descrizioni al parametro/factory di output come descrizioni comandi.
* Aggiunta di funzionalità di reporting (generale) (popup invasivi rimossi e sostituiti con messaggi di fusione nativi).
* Aggiorna l’etichetta della versione di SRE durante l’installazione e l’aggiornamento nelle preferenze di Componente aggiuntivo.
* Correggi Outputsize e casuale non sempre disponibili in una sostanza.

**Sezione Preferenze: aggiunta/aggiornamento:**

* Consente di scorrere/sfogliare la Dimensioni fisiche come predefinito disponibile dall’elenco a discesa shader predefinito.
* Controlla la fusione di proiezione di default Dimensioni fisiche.
* Il collegamento di supporto è stato modificato in modo da puntare al server Discord Server.
* Correggere la visualizzazione della versione corretta di SRE corrente nelle preferenze di aggiunta.
* Mostra tutte le versioni compatibili dell&#39;addon se è necessario un aggiornamento.
* Mostra la matrice delle versioni supportate anziché la prima se manca SRE.

**Sezione del pannello Substance 3D: aggiunta/aggiornamento:**

* La Dimensioni fisiche di un materiale viene visualizzata (in metri) sotto i parametri del grafico.
* La Dimensioni fisiche Cycles/Eevee è disponibile nel menu a discesa dello shader.
* Nascondi gruppi di parametri se tutti i parametri sono invisibili.
