# Disinstallazione del componente aggiuntivo

Per disinstallare il componente aggiuntivo, seleziona Modifica > Preferenze > Componenti aggiuntivi ed espandi la sezione corrispondente.

1. Per prima cosa, rimuovi gli strumenti di integrazione con il pulsante **Disinstalla strumenti**.
1. Quindi rimuovere i file del componente aggiuntivo con il pulsante **Rimuovi**

>[!NOTE]
>
> Se è necessario rimuovere manualmente gli strumenti di integrazione Substance, eliminare la cartella Substance3DIntegrationTools dalla seguente directory
> 
> * **Windows**: C:\Users\(nomeutente)\AppData\Roaming\Adobe
> * **Mac**: /Users/(username)/Library/Application Support/Adobe/Substance3DIntegrationTools
> * **Linux**: /home/(nomeutente)/Adobe/Substance3DIntegrationTools
