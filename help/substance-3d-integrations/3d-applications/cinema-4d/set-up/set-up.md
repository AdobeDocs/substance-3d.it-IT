# Configurazione

## Requisiti

È richiesto Cinema 4D R16 o versione successiva. Sono supportate tutte le versioni del prodotto, ad eccezione di Cinema 4D Lite.

I file di Substance potrebbero essere stati creati utilizzando [Substance Designer](https://www.allegorithmic.com/products/substance-designer).

## Installazione

## Windows

1. Cinema 4D non deve essere in esecuzione durante l&#39;installazione.
1. Esegui il pacchetto di installazione autonoma.
1. Seleziona/seleziona la cartella di destinazione. Questa dovrebbe essere la cartella in cui è stato installato Cinema4D, non la sottocartella dei plug-in.
1. Fare clic su Installa.
1. Dopo aver completato correttamente l&#39;installazione, sarà possibile avviare Cinema 4D.

## MAC OS X

1. Cinema 4D non deve essere in esecuzione durante l&#39;installazione.
1. Rilascia il file cld nella cartella dei plug-in di Cinema 4D.
1. Inizi il Cinema 4D come al solito.
