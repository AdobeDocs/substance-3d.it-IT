# Utilizzo del plug-in Substance

Il plug-in Substance si trova nel menu Plug-in Cinema 4D.

![](../../../assets/cinema-4d-1.png){width="500px"}

## Carica risorsa...

Utilizza questa opzione per caricare le risorse di Substance nella scena. È possibile caricare solo archivi Substance (.sbsar). Se Gestione risorse Substance non è già visualizzato, verrà aperto automaticamente al termine dell&#39;importazione della Substance. Questo comando è disponibile anche in Gestione risorse Substance.

Al momento dell’importazione, ti potrebbe essere chiesto se la Substance deve essere copiata nella cartella del progetto.

![](../../../assets/cinema-4d-2.png){width="500px"}

* Se si risponde &#39;No&#39;, nella scena verrà memorizzato un percorso assoluto della Substance.
* Se rispondi &quot;Sì&quot;, la Substance verrà copiata nella sottocartella tex del progetto e nella scena verrà fatto riferimento solo al nome del file.

Questo messaggio viene visualizzato una sola volta per ogni importazione (ad esempio, quando trascini e rilasci più Substance da Esplora risorse o dal Finder).
