# Importazione in batch

Puoi importare in batch più file di Substance .sbsar utilizzando l’opzione di importazione in batch.

1. Accedi a Substance impostazioni nella parte superiore dell&#39;interfaccia utente di 3ds Max e scegli Substance importazione batch.
1. Scegli i file .sbsar che desideri importare.
