# Utilizzo dei flussi di lavoro in 3ds Max

Il plug-in Substance in 3ds Max contiene flussi di lavoro per la creazione automatica di una rete shader per supportare i moduli di rendering. I flussi di lavoro di rendering si trovano nel menu Substance.

![](../../../assets/workflows-3.png)

Per utilizzare un flusso di lavoro, selezionate il nodo Substance nell&#39;editor materiale e scegliete il flusso di lavoro dal menu Substance.

![](../../../assets/max-workflow.gif)
