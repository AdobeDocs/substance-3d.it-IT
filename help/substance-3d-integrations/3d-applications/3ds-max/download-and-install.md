# Download e installazione

La versione più recente del plug-in viene distribuita in modo nativo da Autodesk con la versione compatibile più recente di 3ds Max. Se è necessaria una build specifica per una versione precedente, trova i collegamenti per il download riportati di seguito.

* **Download per Autodesk 3ds Max 2027:** <https://www.adobe.com/go/substance3d-3dsmax-win-latest>
* **Download per Autodesk 3dsMax 2026:** <https://www.adobe.com/go/substance3d-3dsmax-win-2026>
* **Download per Autodesk 3dsMax 2025:** <https://www.adobe.com/go/substance3d-3dsmax-win-2025>
* **Download per Autodesk 3dsMax 2024** (plug-in versione 3.1.0.): <https://www.adobe.com/go/substance3d-3dsmax-win-2024>
