# Utilizzo dei predefiniti

I file di Substance possono contenere file di predefiniti incorporati. Se una Substance ha un file di predefiniti incorporato, questo viene visualizzato nella finestra Predefiniti di Substance. Potete anche creare dei predefiniti personalizzati in base alle impostazioni scelte per i parametri della Substance.

![](../../../assets/max9.png)

1. Crea predefinito crea un nuovo predefinito in base alle impostazioni dei parametri impostati per la Substance in 3ds Max.
1. Importa predefinito consente di importare un file di predefinito (.sbsprs).
1. Salva predefinito salva i valori dei parametri per il predefinito selezionato.
1. Esporta predefinito selezionato consente di esportare il predefinito nel file del predefinito (.sbsprs).
1. Rimuovi tutti i predefiniti rimuoverà i predefiniti nell’elenco dei predefiniti.
1. Rimuovi predefinito selezionato rimuoverà solo il predefinito selezionato.
