# Substance Source

Puoi utilizzare i materiali Substance da Substance Source nel plug-in 3ds Max v2.

1. Nel menu Substance nella parte superiore dell’interfaccia utente massima di 3ds, scegli Substance Source.
1. Si aprirà un browser e potrai accedere all’abbonamento Source per scaricare i file .sbsar.
1. Importa il file .sbsar in 3ds Max utilizzando il plug-in Substance.
