# Redshift

Il materiale Redshift nella versione 2.5.43 supporta il flusso di lavoro metallizzato. Per il rendering con Redshift, puoi utilizzare le mappe esportate da Substance Painter o dal plug-in Substance in [Maya](https://www.substance3d.com/ecosystem-plug-ins/substance-in-maya/).

Substance Painter 2020.1 (6.1.0) viene fornito con il Redshift ([rsMaterial](https://docs.redshift3d.com/display/RSDOCS/Material)) [Modello di output](https://docs.substance3d.com/display/SPDOC/Export) e un output precedente per Redshift 3.
