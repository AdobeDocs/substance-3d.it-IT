# Thea

Il Convertitore Substance™ consente di creare un materiale Thea da un file SBSAR Substance™. Potete usare i parametri esportati con il file Substance ™ per modificare l’aspetto delle texture e visualizzare anche l’anteprima del materiale Thea creato prima di salvare il risultato finale.

Il Convertitore Substance™ consente di creare un materiale Thea da un file SBSAR Substance™. Potete usare i parametri esportati con il file di Substance per modificare l’aspetto delle texture e visualizzare anche l’anteprima del materiale Thea creato prima di salvare il risultato finale. Potete usare qualsiasi file SBSAR, ma con un materiale Substance ™ basato sul modello PBR Metallico/Rugosità, assicuratevi che anche il materiale Thea creato sia un materiale basato fisicamente.

Per ulteriori informazioni, visita i documenti di rendering Thea. [Convertitore Substance di rendering tema](http://thearender.media/docs/fr/thea-substance-converter/menu)
