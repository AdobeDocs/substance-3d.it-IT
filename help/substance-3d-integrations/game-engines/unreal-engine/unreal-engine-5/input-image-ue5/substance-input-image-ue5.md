# Immagine da Substance - UE5

La Substance può essere creata con input in cui è possibile fornire un’immagine da elaborare nel materiale. Ciò consente di creare materiali modulari che possono accettare dati o pattern mesh cotti come input per modificare o confermare il materiale nella risorsa.

* È possibile utilizzare UTexture2D con un input Substance.
