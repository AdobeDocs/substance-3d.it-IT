# Modelli predefiniti plug-in di Substance 3D

*Nota: questa funzionalità è attualmente in fase di sviluppo e sarà disponibile a breve.*

Con la versione 5.0.0 è stato rinnovato il flusso di lavoro dei modelli di materiale *con output numerici supportati dalla Substance Engine. I modelli di materiale consentono di definire esattamente come configurare gli shader di materiale Substance in UE5.*
