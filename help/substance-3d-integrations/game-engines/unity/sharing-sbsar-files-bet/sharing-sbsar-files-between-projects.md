# Condivisione di file sbsar tra progetti

È possibile condividere file .sbsar tra progetti e computer mantenendo le stesse regolazioni dei parametri con l&#39;utilizzo di file .sbsprs.

Dopo aver modificato il materiale nel progetto originale nelle impostazioni che verranno condivise, accedete alle impostazioni predefinite nel pannello della finestra di ispezione. Nelle impostazioni del predefinito, create un nuovo predefinito e denominatelo. Questo nuovo predefinito con nome verrà visualizzato nell’elenco dei predefiniti per questo materiale. Al termine, esportate il predefinito per salvarlo localmente.

Quando utilizzate il file .sbsar in un altro progetto o computer, includete anche il file del predefinito esportato. Una volta importata la barra secondaria nel progetto Unity, accedi alle impostazioni del predefinito e scegli l&#39;opzione di importazione. Selezionate il file di predefiniti del passaggio precedente e importatelo. Un predefinito con le impostazioni del progetto precedente deve essere aggiunto all’elenco dei predefiniti.

Ripeti l&#39;operazione per tutti i materiali condivisi.
