# Unità 2.5.4

Rilasciato il 9 dicembre 2020

Fisso:

* Impossibile generare app iOS compatibili con il codice bit quando i materiali Substance sono inclusi in un progetto Unity

Problemi noti:

* Impossibile scaricare le risorse da Source in Unity in modo coerente. La soluzione alternativa consiste nel scaricare dal [sito Web Substance Source](https://source.substance3d.com/) e importare manualmente le risorse.
* Unity 2020.2 e versioni successive non sono attualmente supportate
