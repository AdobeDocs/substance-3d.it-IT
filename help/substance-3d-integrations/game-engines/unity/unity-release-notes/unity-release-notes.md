# Note sulla versione di Unity

Al momento supportiamo il plug-in Substance 3D per Unity a partire dalla versione Unity 3.0.0. Le versioni precedenti del plug-in Substance 3D per le versioni precedenti di Unity diventeranno presto obsolete.

**Le versioni di Unity da 2.2.0 a 2.6.0 diventeranno presto obsolete.**
