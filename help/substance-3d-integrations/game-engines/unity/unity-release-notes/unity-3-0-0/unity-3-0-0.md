# Unità 3.0.0

Rilasciato il 27 giugno 2021

Aggiornato/Aggiunto:

* Supporto per Apple Silicon
* Nuova esercitazione di YouTube su come utilizzare il plug-in
* Nuova documentazione sullo scripting
* Supporto per control-z nell&#39;editor di Grafico Substance e nell&#39;editor di file substance principale
* Prestazioni migliorate durante il caricamento di un numero elevato di file sbsar
* Supporto per materiali Substance con grafici multipli
* Modificata l’interfaccia utente per la gestione dei grafici a Substance
* API esposte per caricare un predefinito tramite C#
* Documentazione online aggiornata

Fisso:

* Bug nella finestra di ispezione quando si preme ripetutamente il pulsante di selezione casuale
* Gli input di texture Null interrompono gli aggiornamenti delle Substance
* L’interruttore &quot;Genera tutti gli output&quot;, &quot;Genera mappe mappa mappa mappa&quot; e &quot;Solo runtime&quot; non funziona
* Problemi con gli spazi dei nomi
* Errore di riferimento nullo quando si entra in modalità di riproduzione con la risorsa del grafico selezionata
* Un problema con HDRP e URP per la versione 2021.3 LTS più recente di Unity quando si utilizzano materiali solo per il runtime
* Problemi di prestazioni con file sbsar con più input
* Errori &quot;Handle già rilasciato&quot;
* Problema di tipo &quot;attivazione della modalità di riproduzione blu spostata&quot;
* Problema di mappatura del height con i file sbsar
* Problema con gli input dell’immagine che leggono texture illeggibile

Problemi noti:

* Correzione per un problema di Mac per cui i canali R e B delle texture di output verranno capovolti
* Miglioramenti importanti delle prestazioni di Mac
