# Unità 2.5.3

Rilasciato il 4 novembre 2020

Fisso:

* Arresto anomalo durante la modifica dell&#39;impacchettamento per la mappa di Specular
* La Mappa Specular non è uno Smoothness impacchettamento nel canale Alpha nel progetto 3D standard
* Arresto anomalo al riavvio del progetto HDRP/HRP dopo l’eliminazione della cartella Libreria
* Materiali duplicati senza shader assegnato e proprietà del materiale
* Modifiche del carattere di fine riga nei file di scena e predef.

Problemi noti:

* Impossibile scaricare le risorse da Source in Unity in modo coerente. La soluzione alternativa consiste nel scaricare dal [sito Web Substance Source](https://source.substance3d.com/) e importare manualmente le risorse.
