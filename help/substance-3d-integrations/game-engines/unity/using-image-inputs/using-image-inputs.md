# Utilizzo degli input dell&#39;immagine

Per utilizzare un&#39;immagine in un parametro di input per una Substance:

1. Nella finestra del controllo del Grafico Substance potete selezionare le texture nel progetto da assegnare agli input dell’immagine.

   ![](../../../assets/imageinput-inspector.png)
1. Tenete presente che selezionando una texture verrà controllato il campo &quot;Lettura/scrittura abilitata&quot;, in quanto è necessario per leggere i dati della texture nel materiale della Substance

   ![](../../../assets/imageinput-texture.png)
