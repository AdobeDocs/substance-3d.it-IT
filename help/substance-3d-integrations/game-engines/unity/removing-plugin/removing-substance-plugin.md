# Rimozione del plug-in Substance

Puoi rimuovere i materiali delle Substance prima o dopo l&#39;eliminazione della cartella Adobe e del file Adobe.meta.

1. Chiudete l&#39;Unità. È necessario chiudere Unity per rimuovere il plug-in. Se il progetto è aperto e il plug-in viene rimosso, la reimportazione della dll del motore continuerà.
1. Utilizzando una finestra di dialogo per la scelta dei file, individua la cartella delle risorse ed elimina la cartella di Adobe e il file Adobe.meta.
1. Riavvia Unità.
