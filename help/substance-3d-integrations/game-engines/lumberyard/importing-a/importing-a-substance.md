# Importazione di una Substance

È possibile importare nel progetto un materiale di una sostanza. Una volta copiato il file del materiale Substance (.sbsar) nella cartella del progetto, è possibile utilizzare l&#39;editor del materiale Procedurale per importare la sostanza nel progetto e modificare i parametri Substance.

1. Copia il materiale substance (.sbsar) nella cartella &quot;materials&quot; del progetto. È possibile creare sottodirectory all’interno della cartella dei materiali per scopi organizzativi.

   ![](../../../assets/01-13.png)
1. Fai clic sul pulsante Editor materiale Procedurale nella parte superiore dell’interfaccia utente di Lumberyard per aprire la finestra di dialogo. Nella finestra di dialogo Editor materiali Procedurale, scegliete File > Importa Substance e individuate il file Substance copiato nella cartella Materiali del progetto al passaggio 1. Una volta importate tutte le sostanze, potete chiudere la finestra di dialogo.

   ![](https://helpx-prod.scene7.com/is/image/HelpxProd/2018-01-22-14h10-13?$png$&jpegSize=100&wid=628)
